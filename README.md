## 🎯 Learning Objectives

By using this simulator, you will:

Understand the logical flow of a while loop combined with if/else conditions.

Learn how to perform a Dry Run (tracing code execution manually).

Discover how to track the state of variables in memory using a Trace Table.

Explore the differences in syntax between Python and C++.

## 🚀 How to Use This App

1. Concept Exploration

Start by reading the Concept Breakdown. We use a highly relatable analogy—sorting apples on a conveyor belt—to explain abstract concepts like loops (duration) and conditions (selection). 

2. Interactive Simulator

This is the core of your learning experience.

Language Toggle: Choose between Python or C++ using the buttons above the code.

Dry Run Step: Click the "Next Step" button to execute the code line-by-line. Watch how the highlighted line corresponds to the changes in the "Memory State".

Trace Table: Observe how every variable's value is recorded at each step. This is exactly how computers keep track of data, and mastering this will significantly improve your debugging skills.

3. Think & Link

Before simply reading the answer to the critical thinking question, draft your own hypothesis in the text box. Once you click "Compare with Answer", your input will be locked, and you can compare your logical deduction with the expert analysis. This active recall is crucial for deep learning.

4. Mini-Quiz

Test your understanding at the very end of the page. Select an answer to see immediate feedback explaining the underlying logic.
